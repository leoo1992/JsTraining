# JavaScript Training

A collection of module-based exercises covering JavaScript fundamentals, functions, arrays, asynchronous programming, and data handling.

## Technologies
- JavaScript
- Node.js (for exercises that use Node.js APIs)

## Structure
- `JsFunctionsFundaments - modulo 1/`: function declarations, expressions, arrow functions, anonymous functions, and parameters.
- `JsFunctionsFundaments - modulo 1 - Desafio/`: practical function exercises.
- `JsFunctionsFundaments - modulo 2/`: higher-order functions, `map`, `filter`, and `reduce`.
- `JsFunctionsFundaments - modulo 3/`: additional exercises, including Promises and file reading.

## Run
Install Node.js and verify the installation:

```bash
node --version
```

Run an exercise file from the repository root. Keep the path in quotes because directory names contain spaces:

```bash
node "JsFunctionsFundaments - modulo 1/aula1-fnDeclarada.js"
node "JsFunctionsFundaments - modulo 3/aula7DesafioPromise.js"
```

Each file is an independent exercise. Run it from the repository root to preserve the relative paths used by examples that read files.
