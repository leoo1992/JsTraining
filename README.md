# JavaScript Training

Coleção de exercícios organizados por módulos para praticar fundamentos de JavaScript, funções, arrays, programação assíncrona e manipulação de dados.

## Tecnologias
- JavaScript
- Node.js (para os exercícios que utilizam APIs do Node.js)

## Estrutura
- `JsFunctionsFundaments - modulo 1/`: funções declaradas, expressões, arrow functions, funções anônimas e parâmetros.
- `JsFunctionsFundaments - modulo 1 - Desafio/`: exercícios práticos sobre funções.
- `JsFunctionsFundaments - modulo 2/`: funções de ordem superior, `map`, `filter` e `reduce`.
- `JsFunctionsFundaments - modulo 3/`: exercícios complementares, incluindo Promises e leitura de arquivos.

## Como executar
Instale o Node.js e confira a instalação:

```bash
node --version
```

Execute um arquivo de exercício pelo terminal, informando o caminho entre aspas quando houver espaços:

```bash
node "JsFunctionsFundaments - modulo 1/aula1-fnDeclarada.js"
node "JsFunctionsFundaments - modulo 3/aula7DesafioPromise.js"
```

Cada arquivo é um exercício independente. Execute-o a partir da raiz do repositório para preservar os caminhos relativos usados pelos exemplos que leem arquivos.
